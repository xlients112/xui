# X-UI

A slint component for mobile apps, built with elegant, reusable and dynamic design.
## Documentation
x-ui component has several prebuilt widgets that are already provided, creating widgets with raw components, but there are several widgets that have not been added.

But you can use this as a reference for your design, take it, edit widgets, customize colors, and so on.
## Features

- Light/dark mode toggle
- input text type: text, password, searchbar, typing.
- Button
- dockbar
- row space
